# 収録プラグイン

各プラグインと、収録している skill の一覧です。

## [`coding-workflow`](agent-toolbox/coding-workflow)

バックエンド設計、コードと README の規約、Git、TDD など、実装工程全体のワークフローを扱います。

収録 skill は [`backend-patterns`](agent-toolbox/coding-workflow/skills/backend-patterns/SKILL.md)、
[`coding-standards`](agent-toolbox/coding-workflow/skills/coding-standards/SKILL.md)、
[`git-workflow`](agent-toolbox/coding-workflow/skills/git-workflow/SKILL.md)、
[`tdd-workflow`](agent-toolbox/coding-workflow/skills/tdd-workflow/SKILL.md)。

## [`general-tools`](agent-toolbox/general-tools)

AWS、GitHub Actions、Terraform の安全な運用と開発規約を扱います。

収録 skill は [`aws-cli`](agent-toolbox/general-tools/skills/aws-cli/SKILL.md)、
[`gh-actions`](agent-toolbox/general-tools/skills/gh-actions/SKILL.md)、
[`terraform`](agent-toolbox/general-tools/skills/terraform/SKILL.md)。

## [`planning-review-docs`](agent-toolbox/planning-review-docs)

実装計画とセキュリティレビューを扱います。

収録 skill は [`planner`](agent-toolbox/planning-review-docs/skills/planner/SKILL.md)、
[`security-review`](agent-toolbox/planning-review-docs/skills/security-review/SKILL.md)。

## [`specialized`](agent-toolbox/specialized)

失敗の再発防止に向けた事後検証と、媒体に依存しない技術記事作成を扱います。

収録 skill は [`postmortem`](agent-toolbox/specialized/skills/postmortem/SKILL.md)、
[`write-articles`](agent-toolbox/specialized/skills/write-articles/SKILL.md)。
